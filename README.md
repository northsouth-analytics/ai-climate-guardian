# AI Climate Guardian

Team NorthSouth Analytics, NASA Space Apps Challenge 2026.
Challenge: Be An Earth System Trend Detective!

We compare July temperature trends from 2019 to 2026 in four US climate zones (Phoenix, Seattle, Denver, Miami) using NASA POWER data (parameter T2M, from the MERRA-2 model).

Results (degrees C per year): Denver +0.185, Miami +0.113, Phoenix +0.051, Seattle -0.256.
Limitations: 8 years, one month per year, one dataset. We do not claim statistical significance.

Run: upload climate_guardian_final_v8.py to Google Colab and run it. It needs Python and matplotlib.

AI use: Claude (Anthropic) was used as a coding and learning assistant.
